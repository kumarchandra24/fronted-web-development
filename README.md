## Code Formatting

The files use consistent indentation, readable line breaks, meaningful IDs/classes, and organized HTML/CSS/JavaScript so they are suitable for formatting with **Prettier** in VS Code.

Recommended VS Code setting:

1. Install the **Prettier - Code formatter** extension.
2. Open the project folder.
3. Use `Alt + Shift + F` on a file.
4. To format on save, enable **Editor: Format On Save**.

## Running the Project

No server is required for the basic HTML/CSS/JavaScript experiments.

1. Extract the ZIP file.
2. Open `index.html` in a browser.
3. Select HTML, CSS, or JavaScript.
4. Open any experiment from its list.

Some API-based experiments require an internet connection because they use browser `fetch()` requests.
